- Fix: Added `deleteByModuleId` + `countByModuleId` to `FirmModuleRepository`
- Updated `deleteModule` to cascade delete: collects all descendant module IDs, batch-deletes `module_permissions` + `firm_modules` for each, then lets JPA `CascadeType.ALL` handle the module rows
- Removed sub-module and permission count guards — they're now cleaned up automatically
- Injected `FirmModuleRepository` into `ModuleServiceImpl`
