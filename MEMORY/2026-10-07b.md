# 2026-10-07 (cont.)

## Firm brand + logo + profile frontend contract

Built on the firm admin surface, with the user's stated defaults baked in:
- **New fields on `Firm`**: `logoAllowed` (boolean, default off — `ALTER TABLE firms ADD COLUMN logo_allowed boolean NOT NULL DEFAULT false` once the migration is finalized; starter SQL currently says `DEFAULT true` and will be flipped before applying), `brandPrimaryHex` / `brandSecondaryHex` (varchar(7), nullable).
- **Strict hex**: new `BrandColorValidator.normalizeHex("#rrggbb or rrggbb → #rrggbb, lowercase)". Rejects anything else.
- **Logo allowed flag**: firm can toggle `logoAllowed` on/off; when off, logo upload is rejected with `403`. Newly created firms default logo off so a logo only ever appears when the firm chooses it.
- **isPersonalColor**: when the firm has set at least one of primary/secondary, the portal shows the firm's own colors; otherwise it shows the app's default. Mirrors the existing brand-color firm-config behavior but exposes it on the `me.firm` payload as a boolean so the portal can decide in one lookup.
- **Logo storage**: new `FirmStorageService` writes logos into `StorageService` under `firms/{firmId}/logo.{ext}` (png/jpg/jpeg/webp only, ≤ 200 KiB), deletes the prior object before setting the new url, and computes the presigned logo URL via the new `StorageService.presignFirmLogo(UUID)` helper added to `MinioStorageService`.
- **DTO surface**: `SetFirmThemeRequest`, `SetLogoAllowedRequest`, `SetLogoUploadRequest` (multipart part), `LogoResponse`; `FirmProfileResponse` and `MeResponse.firm` now expose `logoUrl`, `logoAllowed`, `brandPrimaryHex`, `brandSecondaryHex`, `isPersonalColor`.
- **Endpoints** (all firm-admin-only via `@PreAuthorize("hasRole('FIRM_ADMIN')")` on `FirmProfileController`): `GET/PUT /api/v1/firm/brand/theme`, `GET/POST /api/v1/firm/brand/logo`, `PATCH /api/v1/firm/brand/logo/allowed`. Change-own-password is unaffected and already at `POST /api/v1/me/change-password`.
- **Docs**: `docs/firm-brand-profile-guide.md` — change-own-password (existing), theme (strict hex, isPersonalColor rendering rule), logo (default off, upload caps, presigned-link expiry note), and the `me.firm` payload.
