## RBAC Simplification — Template Layer Removed

- **Removed entire template/sync infrastructure**: `TemplatePermissionService`, `TemplateSyncPlanner`, `TemplateSyncRunner`, `FirmSyncExecutor`, `SyncJob` entity+repo, 4 DTOs, 4 controller endpoints, all cascade logic (~900+ lines deleted)
- **Simplified Role entity**: removed `parentRoleId`, `lastSaEditAt`, `extendsRole` fields
- **New ceiling model**: FIRM_ADMIN has no ceiling (SA sets via override), other roles ceilinged by FIRM_ADMIN's enabled permissions
- **Simplified FirmRoleServiceImpl**: removed cascade logic, `computeCeiling()` now returns all non-GLOBAL permissions for FIRM_ADMIN, firm FIRM_ADMIN's perms for other roles
- **Simplified RolePermissionServiceImpl**: removed parent_role_id ceiling check, only GLOBAL scope check remains
- **Cleaned up**: DataInitializer (removed backfillCustomRoleParentIds + seeder freeze), RoleController (removed template endpoints), RoleManagementService (removed getSystemTemplates), RbacConstants/SuperAdminConstants (removed template constants), AuditAction (removed TEMPLATE_PERMISSION_CHANGED)
- **8 new E2E tests** in `SimplifiedRbacE2ETest`: full SA→Firm→Ceiling→FirmAdmin→Employee flow, multi-firm isolation, SA custom role on-behalf, ceiling enforcement
- **325 tests, 0 failures** — all existing + new tests pass

## Key Design Decisions
- FIRM_ADMIN ceiling = no ceiling (all non-GLOBAL permissions available)
- Other roles ceiling = firm FIRM_ADMIN's enabled permissions
- SA sets FIRM_ADMIN permissions via `PUT /super-admin/firms/{firmId}/roles/{roleId}/permissions`
- Firm Admin distributes subset to employee roles via `PUT /firm/roles/{roleId}/permissions`
- Per-firm isolation: Firm A and Firm B are completely independent
- Custom roles: SA can create on-behalf, Firm Admin can create within firm
