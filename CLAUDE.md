# Project instructions

## gstack

Use the **`/browse`** skill from gstack for all web browsing. Never use `mcp__claude-in-chrome__*` tools.

gstack is cloned into this repo at **`.agents/skills/Gstack`** (version 1.91.93.0).
Run `./setup` from that directory to build the browser binary and register the skills.
